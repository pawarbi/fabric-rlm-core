# Coarse to detail analysis

Use this procedure only when a question asks for a leading group and then a
breakdown within that group. Inspect the source columns and sample values first.
Identify the grouping, detail, and numeric measure from the question and the
source; never assume a particular domain or column name.

Aggregate the measure by the broad group, choose the leading group, then
filter to that exact group before aggregating by the detail. Include every
source row that belongs to the selected group. Recalculate both submitted
totals from the data and explain if the required fields are absent or unclear.
